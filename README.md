# justVedio 0.3.1

Windows 10/11 64 位身份登录与视频学习助手。参考本机 `E:\Other\codex\vedio` 的 AnsweringVideo 0.2.4 创建独立项目，保留登录、队列、播放监测和导出功能，移除题库及答题流程。

## 启动

使用免安装包时，完整解压 `justVedio-Portable-0.3.1-x64.zip`，双击 `justVedio/justVedio.exe`；本轮也可直接运行 `dist/v0.3.1/justVedio/justVedio.exe`。EXE 与 `_internal` 文件夹须保存在一起。包内包含 Python、Qt、OCR 模型、Playwright 驱动及备用 Chrome，无需另装 Python。

本地源码可双击 `启动软件.cmd`。从源码准备环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

完整复现开发及构建环境可安装 `requirements-lock.txt`；普通使用安装 `requirements.txt` 即可。程序自动发现系统已安装的 Chrome / Edge 等浏览器，并在“执行”页勾选；免安装包另含随附浏览器作为备用。每个浏览器使用独立的临时配置和调试端口；Edge 首次运行的 NTP/隐私提示会自动处理或跳过，不会留下额外窗口。Edge 冷启动偶发失败时会自动换新临时配置重试一次，重试仍失败才把该路标记为失败。多个浏览器可同时工作。

## 人员信息

exe 同级目录（源码运行时为项目根目录）的 `人员信息` 文件夹存放身份表。软件启动时自动加载其中**所有** `.xlsx`，按身份证号合并并拒绝重复；也可以按 `Ctrl+O` 手动导入单个文件。表头必需列为“所在的区县、姓名、身份证号”，身份证列使用文本。拒绝缺失、重复、格式错误及存在精度风险的身份证数据。

## 使用

1. 在“执行”页勾选浏览器。默认只勾选第一个可用浏览器，可刷新、全选；勾选结果保存供下次沿用。
2. 点击 **启动视频学习**。每位身份使用一个**新浏览器窗口**；勾选几个浏览器就是几路并发，每路同一时间只处理一人，完成或失败后立即从共享队列接下一位，直到当天所有未完成身份处理完。
3. 登录成功后，软件先判断主页是否已经显示“再次考试/本年度网考已完成”且没有旁听入口；如果是，说明该身份已经完成，直接记为**本日已完成并跳过**。否则查找“开始旁听学习”或“继续旁听学习”并点击；既没有完成标志也找不到入口时，才记为失败。
4. 进入视频页后，软件会先点击画面中央（白色三角形或视频区域），并依次尝试常见播放控件、视频元素点击和浏览器播放接口；只有确认媒体确实开始前进后才停止操作。视频播放器即使尚未预加载，也会先尝试播放而不是直接报错。
5. 播放结束后，如页面出现“确认完成”（兼容“确认完成学习/完成学习”）会自动点击；页面出现“网考流程已完成”时点击“返回考生主页”（找不到按钮时直接打开登录后的主页地址）。
6. 返回主页后，软件确认“再次考试”出现，且“开始/继续旁听学习”“进入考试”都消失（也识别“本年度网考已完成”），立即关闭浏览器，记为“学习完成”，该路自动接下一位。只有确认到该完成状态才算完成。
7. 失败情形：找不到旁听学习入口、主页只有“进入考试”按钮（会提示“发现进入考试按钮，请先完成考试”）、视频未开始播放、视频加载/解码失败、页面或浏览器提前关闭、超过最长等待时间、未能点击确认/返回主页、返回主页后仍有旁听学习或进入考试入口、未出现“再次考试”、浏览器未能关闭。失败身份关闭浏览器后同样让出该路。
8. “暂停补位”只暂停新身份，当前身份继续；“停止”可等待当前身份完成，或立即停止；**停止后不会关闭已经打开的浏览器**，可以手动关闭。关闭软件时同样不会关闭浏览器，正在播放的学习会继续。若上次退出时浏览器仍在运行，请先关闭对应旧窗口再重试同一身份，避免平台只允许一个有效会话。
9. 学习批次以**天**为单位：`学习完成_YYYYMMDD.xlsx`、`学习失败_YYYYMMDD.xlsx` 每天各一个，当天多次运行会合并并按身份证号去重；已完成身份不会再出现在失败文件中。文件内容格式与导入模板一致（区县/姓名/身份证号）。同时在结果目录保存包含浏览器列的详细统计与 `人员状态.json`。界面与日志脱敏，记录文件保留完整身份信息，请妥善保管。
10. 主界面右上角显示**累计完成学习**人次：每成功完成一位就加 1，同一人再次学习完成也再次计入，不会因新批次而清零；已经完成、无需再学的身份不会重复累加。累计值保存在软件目录的 `results/学习累计统计.json`；首次升级后如果该文件不存在，会从已有 `学习完成` 记录和每日台账汇总初始值。
11. 每日台账保存在 `results/每日学习/YYYY-MM-DD.json`，按身份证号去重；当天已完成的身份再次导入会直接显示为已完成，不会重新进入队列。失败/中止的身份可以再次点击启动重试，成功后会自动从“未完成”移到“已完成”。

## 学习设置

“学习”页可调整：学习入口文字（默认 `开始旁听学习|继续旁听学习`）、播放按钮选择器（留空时自动点击视频中央）、完成确认文字（默认 `确认完成学习|完成学习|确认完成`）、返回主页文字（默认 `返回考生主页|返回主页`）、视频元素、视频 iframe 及最长等待时间。程序不修改播放位置、倍速或平台完成接口。

## 目录与设置

- `人员信息`：启动时自动加载的身份证表文件夹。
- `学习完成` / `学习失败`：按天合并去重后的学习结果，格式同导入模板。
- 详细批次统计默认保存在源码或 EXE 旁的 `results`。
- `results/每日学习/YYYY-MM-DD.json`：当天按身份证号去重的学习状态台账。
- `results/学习累计统计.json`：累计完成学习人次，跨批次保留。
- 设置空间为 `LocalTools/justVedio`，不自动迁移参考项目设置。
