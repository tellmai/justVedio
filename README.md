# justVedio 0.3.0

Windows 10/11 64 位身份登录与视频学习助手。参考本机 `E:\Other\codex\vedio` 的 AnsweringVideo 0.2.4 创建独立项目，保留登录、队列、播放监测、导出和有效期功能，移除题库及答题流程。

## 启动

使用免安装包时，完整解压 `justVedio-Portable-0.3.0-x64.zip`，双击 `justVedio/justVedio.exe`。EXE 与 `_internal` 文件夹须保存在一起。包内包含 Python、Qt、OCR 模型、Playwright 驱动及备用 Chrome，无需另装 Python。

本地源码可双击 `启动软件.cmd`。从源码准备环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

完整复现开发及构建环境可安装 `requirements-lock.txt`；普通使用安装 `requirements.txt` 即可。程序自动发现系统已安装的 Chrome / Edge 等浏览器，并在“执行”页勾选；免安装包另含随附浏览器作为备用。

## 人员信息

exe 同级目录（源码运行时为项目根目录）的 `人员信息` 文件夹存放身份表。软件启动时自动加载其中**所有** `.xlsx`，按身份证号合并并拒绝重复；也可以按 `Ctrl+O` 手动导入单个文件。表头必需列为“所在的区县、姓名、身份证号”，身份证列使用文本。拒绝缺失、重复、格式错误及存在精度风险的身份证数据。

## 使用

1. 在“执行”页勾选浏览器。默认只勾选第一个可用浏览器，可刷新、全选；勾选结果保存供下次沿用。
2. 点击 **启动视频学习**。每位身份使用一个**新浏览器窗口**；勾选几个浏览器就是几路并发，每路同一时间只处理一人。
3. 登录成功后，软件在考生主页查找“开始旁听学习”或“继续旁听学习”并点击。**找不到这两个入口时，该身份直接记为失败**，关闭其浏览器并让这一路接下一位。
4. 进入视频页后点击视频中间的播放按钮（白色三角形）；确认视频确实在播放后，软件不再操作浏览器，直到播放结束。
5. 播放结束后，如页面出现“确认完成学习/完成学习”会自动点击；随后点击“返回考生主页”（失败时直接打开登录后的主页地址）。
6. 返回主页后软件关闭该浏览器，并以**浏览器进程关闭**作为该身份的学习完成信号，记为“学习完成”，该路自动接下一位，循环往复。
7. 失败情形：找不到旁听学习入口、视频未开始播放、视频加载/解码失败、页面或浏览器提前关闭、超过最长等待时间、未能返回主页、浏览器未能关闭。失败身份关闭浏览器后同样让出该路。
8. “暂停补位”只暂停新身份，当前身份继续；“停止”可等待当前身份完成，或立即停止（立即停止会关闭当前浏览器）。**关闭软件时不会关闭已打开的浏览器**，正在播放的学习会继续。
9. 每批在 `学习完成`、`学习失败` 文件夹各写一个 xlsx，文件名取自点击“启动视频学习”的时间（如 `学习完成_20261106_180000.xlsx`），内容格式与导入模板一致（区县/姓名/身份证号）。同时在结果目录保存包含浏览器列的详细统计与 `人员状态.json`。界面与日志脱敏，记录文件保留完整身份信息，请妥善保管。

## 学习设置

“学习”页可调整：学习入口文字（默认 `开始旁听学习|继续旁听学习`）、播放按钮选择器（留空时自动点击视频中央）、完成确认文字（默认 `确认完成学习|完成学习`）、返回主页文字（默认 `返回考生主页|返回主页`）、视频元素、视频 iframe 及最长等待时间。程序不修改播放位置、倍速或平台完成接口。

## 目录、设置与有效期

- `人员信息`：启动时自动加载的身份证表文件夹。
- `学习完成` / `学习失败`：按批次写入的学习结果，格式同导入模板。
- 详细批次统计默认保存在源码或 EXE 旁的 `results`。
- 设置空间为 `LocalTools/justVedio`，不自动迁移参考项目设置。
- 有效期至北京时间 **2027-05-20 当天**；次日 00:00 起提示“软件已过期，请联系1564532736@qq.com”，运行中的队列也会停止。本地时间校验不能防止修改电脑时间。
